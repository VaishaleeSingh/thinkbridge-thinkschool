3. What the migration actually emitted (SQLite)
-------------------------------------------------------------------------------

From the startup log of the first run after the migration was generated,
confirming the three properties the design calls load-bearing:

CREATE TABLE "OutboxMessages" (
    "Id" INTEGER NOT NULL CONSTRAINT "PK_OutboxMessages" PRIMARY KEY AUTOINCREMENT,
    "MessageId" TEXT NOT NULL,
    "EventType" TEXT NOT NULL,
    "SchemaVersion" TEXT NOT NULL,
    "Payload" TEXT NOT NULL,
    "TraceParent" TEXT NULL,
    "OccurredAtUtc" TEXT NOT NULL,
    "Status" TEXT NOT NULL,
    "Attempts" INTEGER NOT NULL,
    "LastError" TEXT NULL,
    "LockedUntilUtc" TEXT NULL,
    "LockOwner" TEXT NULL,
    "SentAtUtc" TEXT NULL
);
CREATE UNIQUE INDEX "IX_OutboxMessages_MessageId" ON "OutboxMessages" ("MessageId");
CREATE INDEX "IX_OutboxMessages_Pending" ON "OutboxMessages" ("Status", "Id") WHERE [Status] = 'Pending';
CREATE INDEX "IX_OutboxMessages_SentAtUtc" ON "OutboxMessages" ("SentAtUtc");

  - MessageId is UNIQUE                          as required
  - IX_OutboxMessages_Pending carries the filter as required
  - Payload is TEXT, uncapped                    as required

The SQL Server migration was checked against the same three: Id bigint
IDENTITY, MessageId nvarchar(128) unique, the same filter predicate, and
Payload nvarchar(max).

4. The claim query, as the relay actually issued it
-------------------------------------------------------------------------------

Logged by the EF command interceptor on the relay's first pass. This is the
provider-neutral shortlist read; the conditional UPDATE checked for
rows-affected follows it and is the actual guarantee.

SELECT "o"."Id", "o"."Attempts", "o"."EventType", "o"."LastError",
       "o"."LockOwner", "o"."LockedUntilUtc", "o"."MessageId",
       "o"."OccurredAtUtc", "o"."Payload", "o"."SchemaVersion",
       "o"."SentAtUtc", "o"."Status", "o"."TraceParent"
FROM "OutboxMessages" AS "o"
WHERE "o"."Status" = 'Pending'
  AND ("o"."LockedUntilUtc" IS NULL OR "o"."LockedUntilUtc" < @now)
ORDER BY "o"."Id"
LIMIT @p

And the lease release on graceful shutdown:

UPDATE "OutboxMessages" AS "o"
SET "LockedUntilUtc" = NULL,
    "LockOwner" = NULL
WHERE "o"."LockOwner" = @_owner AND "o"."Status" = 'Pending'

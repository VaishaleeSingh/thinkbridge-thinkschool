Signal Forms demo

The same author/text/background fields as the "New quote" dialog, rebuilt with the experimental @angular/forms/signals preview API instead of reactive forms. Submitting always simulates a 900ms request, and always simulates the server rejecting the selected background -- change the background to a different option and resubmit to see it save.
